# Banking Analytics Dashboard & SQL Analysis

## Overview

This project analyses a retail banking dataset containing approximately 60,000 customers, 22,000 loans, customer accounts, payment cards, and financial transactions across 136 branches. Using SQL for data extraction, transformation, and analysis, the project uncovers insights into customer behaviour, branch performance, loan portfolio health, operational efficiency, and credit risk.

The project demonstrates how SQL can be used to transform raw banking data into actionable business intelligence that supports strategic decision-making. Key analyses include customer segmentation, account performance, transaction trends, card portfolio analysis, loan performance, branch-level risk assessment, and data quality validation.

---

## Project Objectives

The primary objectives of this project were to:

- Analyse customer demographics and acquisition trends.
- Evaluate account activity and identify dormant accounts.
- Examine transaction behaviour and cash flow patterns.
- Assess payment card utilisation and operational risks.
- Measure loan portfolio performance across different loan statuses.
- Identify high-risk loan products and branch-level credit risk.
- Detect data quality issues affecting reporting accuracy.
- Generate business recommendations to improve profitability, operational efficiency, and credit risk management.

---

## Key Insights

- Analysed approximately 60,000 customers across 136 branches.
- Evaluated a portfolio of approximately 22,000 loans.
- Identified 3,530 dormant accounts holding ₹4.72 billion.
- Found 40,945 expired payment cards requiring lifecycle management.
- Determined that 90.25% of loan value is either Active or Closed, while 9.75% represents Defaulted or Written-off loans.
- Identified Education Loans and Gold Loans as the highest-risk lending products.
- Revealed significant differences in default rates across branches, highlighting opportunities to improve underwriting and portfolio management.
- Identified data integrity issues involving closed loans with missing repayment records.
